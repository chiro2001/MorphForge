# 模型与所选动画一起发布（Desktop 0.26.0）

主界面新增“随版本发布的动画”，与分组动画面板的片段选择同步。点击“发布当前版本”会通过一次HTTP请求发送模型、所选片段的定义、几何分组绑定及播放控制。定义与绑定完成后开始播放；关闭动画面板仍保留选择。沿用面板速度和预览时间，单次动画在末尾发布时从头播放。

未保存的编辑会在发送前提示保存。后端校验工程、模型版本、创作资产版本、片段存在性、头像能力与运动范围；失败不会降级为静态发布，也不增加提交记录。无新片段选择时仍可发布模型，并保留已绑定动画。补播、重建及独立的暂停/继续入口继续可用。

- 原生验收使用从正式NSIS解包的实际载荷，并核对内嵌页面与最终源码哈希。[构建输入](source-freeze.json)284个文件，构建前后摘要一致；[载荷哈希](windows-payload.json)。
