# 四行双语实时字幕（Desktop 0.25.0）

同一个字幕框现在同时显示原文和译文。默认新建字幕框为**四行、128×40格、字号8、行距2**：上方原文、下方译文，各保留最近最多两行。两种文字分别限行，长译文不会挤掉原文，字号保持不变。

等待新译文时，原文继续实时更新，下方保留上一版译文；首次没有译文时先显示原文。译文返回后，最终双语内容会同时写入保存文本和实时发送队列，循环补播也恢复最终双语内容。翻译失败仍显示原文并提示错误。完整识别原文仍可在小窗修改。

新建按钮、模型创建的caption预设和工具推荐配置统一为四行。已有自定义框仍尊重原有行数与尺寸；例如三行框分配两行原文、一行译文。双语至少需要两行高度，过矮框会提示增高，不会偷偷缩小字号。可在文本框设置中调整最大行数和框高。

所有字幕继续共享每框128字符槽（包括换行）。默认四行满宽英文会多出换行槽，本轮在预览与发送的共同排版层保留最新内容，使两端一致，避免超出容量。双语独立分配原文/译文字符预算。仍只占一个文本框，沿用当前Avatar 1.3.0及原有OSC协议。

预览字形采样增加整数取整与边界限制，避免抗锯齿边缘采到相邻字形。
