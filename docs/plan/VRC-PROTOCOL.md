# VRC适配器与MF3/56bit

## 固定基线

PC/PCVR；接受Very Poor。已有MF2为10数据Int+Ctl=88bit，独立于MF3保留。MF3主档为D00..05+Ctl共7个Int=56bit。位置/尺寸各3字节；共享brush保存styleId(12)、tintId(6)、motion(6)。Meta在独立命令中设置，本地缓存不进Expression。

MF3操作码：1 Box，2 UnitVoxel，3 EraseRegion（原生中心擦除语义），4 RemoveExact，5 Clear，6 SetBrush，7..15预留。Ctl采用op4+seq4，16序号循环；6×16=96捕获状态，比MF2的128更少。brush命令不自动画盒，后续几何在执行Latch从持久Brush复制到W快照；BrushApply从已经锁存的W载荷更新持久Brush，不能在释放Inbox后继续读Q，不能执行中被下一brush改变。MF3命名空间避免旧MF2发送器误绘。

本版刷子的 `motionPhase` 是6bit时间相位，用于材质翻帧及云水表面效果，不是逐Box的位置、速度或骨骼动画。后续实体运动可用预留操作码设置共享运动预设、速率、振幅与中心，再把预设快照写入粒子可用的持久通道；需要先验证原生存储和Shader解码，不把未实现的运动字段塞进现有几何6字节，也不改变本版接口含义。

高层任意区域挖洞仍由Rust几何相减编译为Remove+Box；Remove原生擦除半格中心定位的精度需回归。6数据Int足够一批长方体，改变刷子额外批次；5k理想1250秒（20m50s）、16384理想4096秒（1h8m16s），不计重传/刷子/清空。串行低bit档先保留架构扩展，不能声称HTTP bulk已提高Avatar带宽。

## 预算

完整面捕按161bit固定；几何56；定位World1+Handle1+Scale8+Reset1+GrabL/R2+Level1=14。其它本体/衣装/道具及所有压缩carrier最多25bit。原上传原始289/压缩256仅作为审计输入，按最终合并结果算。若必要面捕依赖在FT前缀外，也纳入完整保留集合。

MA安装模块，VRCFury保持现有面捕/低频同步。压缩器可优先处理低频外观，实时输入与MF3命令保持直通。改sync要记录功能/远端影响，不从已压缩参数原始大小直接计算回收量。理论上可通过本体精简/串行适配，但不在最终报告前保证装得下。

## 定位与测试

球为底部中心，默认世界固定；World切换、本人手接近握拳抓取/松手、复位、缩放、水平锁定。水平保留yaw，消除pitch/roll；不依赖Avatar自定义MonoBehaviour。所有参数以MA注入。

用户单Avatar场景保留，仅补Editor测试接收器自动Play初始化、可配置本机OSC接收/输出端口；探测descriptor而非固定对象名。关闭Play时释放端口。不得停用用户其它内容或重开旧多Avatar场景。源代码部署后等待重编译完成再运行Pipeline。

## 16k验证与同步

A原生存储/渲染夹具快速预填（显式标记非OSC），测64/1k/4k/16k的数量、帧时间、内存、材质模式；B真实UDP逐条提交完整16384不可合并Box，检查接收/完成/坐标/外观、序号回绕、16k满容量、删除补回与清空；C用户上传后客户端及多人验证。A不能代替B/C。

单写入发送器异步追目标，增量、快照重建、周期刷新同队列。无远端ACK，sent仅表示本机发包完成。16k全量刷新按当前速率很慢，必须显示周期/进度和可调策略；重复结构命令由Avatar本地展开需另做原型，不能伪称已优化。

官方评级不是PC硬容量线；Limiter、用户过滤、Trigger表现与客户端帧时间独立验收。单个立方体12三角形，16384为196608绘制三角形；不要与单个mesh的Limiter面数配置混算。
