# MorphForge 0.27.0 スタートガイド

MorphForge Avatar 1.4.0 同梱。2026-10-25。

Windows 用のボクセル・図形制作ワークベンチです。手動編集、Recipe の実行、自分の大規模言語モデル API による制作補助に対応します。自分の Humanoid Avatar にモジュールを導入・アップロードすると、OSC 経由で VRChat PC/PCVR にモデル、点・線、テキスト、グループアニメーションを表示できます。人物アバターは付属しません。

## 動作環境

- Desktop：Windows x64、WebView2（Microsoft Edge）、WebGL が動作するグラフィックス環境。macOS/Linux 用インストーラーは同梱しません。
- 検証構成：Unity 2022.3.22f1、VRChat SDK 3.10.5、Modular Avatar 1.18.7、NDMF 1.14.8。VRCFury 1.1430.0 は任意。VCC から別途導入してください。
- PC/PCVR 向け。Quest/Android 単体動作は未検証です。Very Poor ランクを前提としたモジュールであり、実機 FPS は保証しません。
- 標準で **253 bit** の同期パラメーターを使用（図形240＋配置13）。導入前に Avatar をバックアップし、残り容量を確認してください。VRCFury で圧縮できるのは適した低頻度メニューパラメーターです。OSC データや連続的な顔トラッキングは圧縮できず、最終予算超過時はビルドを停止します。

## Desktop の導入

1. `Windows/MorphForge Desktop_0.27.0_x64-setup.exe` を実行します。
2. 設定の表示言語で「システムに従う / 简体中文 / 日本語 / English」を選べます。再起動せずに切り替わります。
3. 作品ライブラリから「会转动的风车」などのサンプルを読み込みます。手動編集と内蔵サンプルには API Key は不要です。
4. AI 制作と字幕翻訳には、ご自身の Chat/Responses 互換 API を設定してください。キー・利用枠は付属せず、サービス料金は別途発生します。表示言語、制作指示、音声認識、翻訳先言語は独立しています。

## Avatar への導入

1. シーンをバックアップし、VCC の Avatar プロジェクトに SDK、Modular Avatar、NDMF を導入します。
2. `Unity/MorphForgeAvatar-1.4.0.unitypackage` をインポートします。
3. `Tools > MorphForge Avatar > Setup - 安装 - 設定` を開き、対象 Avatar と言語を選んでインストールします。圧縮ブリッジを使う場合は先に VRCFury を導入してください。
4. 旧 MF6 モジュールは重複受信を防ぐため先に削除します。共有コントローラーの Write Defaults On を手動で削除しないでください。シーンを保存し、通常どおり SDK でビルド・アップロードします。
5. 言語はプラグイン画面とその Avatar のメニューに適用されます。既存モジュールのメニューも更新できます。**VRChat 内に反映するには Avatar の再アップロードが必要です。**
6. Desktop の材質認識が一致しない場合は `Unity/MorphForge-public-catalog.zip` を読み込み、Avatar を再認識してください。544 材質の標準モジュール用です。独自の画像テクスチャを使う派生版には、その派生版と一致するカタログが必要です。

## 最初の送信とアニメーション

1. VRChat でアップロード済み Avatar に変更して OSC を有効にします。Desktop の接続画面で Avatar を認識し、機能バージョン **9** と材質カタログを確認します。接続できない場合はポート、ファイアウォール、旧 Avatar のキャッシュを確認してください。
2. 「会转动的风车」サンプルを読み込み、編集画面で風車の回転を確認します。
3. 保存済みアニメーションが一つだけなら自動選択されます。複数ある場合はメイン画面の送信欄で選びます。「現在のバージョンを送信」でモデルと選択中のアニメーションを一緒に送信します。静的表示を選ぶとモデルのみ送信します。
4. 各送信段階の完了後、VRChat で羽根が連続回転するか確認します。100% はローカル UDP の送出完了です。**受信側の実行 ACK はありません。** 全プレイヤーの完全受信を保証する表示ではありません。
5. 途中参加や受信漏れには再送・ループ再送を使用します。最新のモデル、テキスト、アニメーション定義を再送します。大きな作品は転送に時間がかかり、瞬時の同期や端末間の厳密な位相一致は保証しません。

## 点・線、テキスト、音声字幕

点の直径、線分の太さと両端点を直接指定できます。専用コマンドと Avatar のネイティブなパーティクル・Shader を利用し、毎フレーム頂点を送信しません。図形容量は共通です。太さは空間上のサイズなので、距離により見かけの大きさが変わります。

テキスト枠は最大4個、各128 UTF-16 スロット（改行を含む）。中・日・英のドット字形、半角・全角、文字サイズ、位置、向き、行間、色、枠の範囲を設定できます。BMP 外の文字は代替表示になる場合があります。文字組みは Desktop 側で行い、Avatar が受信した文字と配置を表示します。

新しい音声字幕は固定文字サイズの4行が標準です。原文と翻訳をそれぞれ最新2行まで表示します。翻訳先は中国語・日本語・英語から選択し、原文を残します。自動翻訳は標準で無効、ご自身の大規模言語モデル API を使用します。既存の字幕枠は設定を維持するため、必要なら最大行数とあふれ処理を調整してください。音声字幕と通常テキスト枠は4枠を共有し、ボクセル・アニメーションと併用できます。

小型の Silero VAD は付属します。SenseVoice/Zipformer の音声認識モデルは別途ダウンロードが必要です。Tencent Cloud はご自身の認証情報を使用します。録音、クラウド認識、翻訳は利用者が有効にしてください。利用枠は付属しません。

## 制限とパフォーマンス

- 論理範囲256³、X/Z -128…127、Y 0…255。Avatar 設定容量は16,384図形。本版では最大容量16Kのネットワーク無損失長時間試験を再実施していません。
- Avatar アニメーションは3グループ×4キーフレーム。移動、回転、正の一様拡縮、ループ/単発、停止/再開/位置指定に対応します。時間プリセット0.125…64秒。編集画面の全機能とは異なり、送信前の検査結果に従ってください。
- 単色・量子化PBR・手続き型材質はリアルタイム送信できます。新しい画像テクスチャには Unity での派生版作成と Avatar 再アップロードが必要です。
- 汎用の物理コリジョンはありません。大量の図形や透明面の重なりは性能や描画に影響します。小規模な作品から確認してください。編集画面と実際のワールドの見え方は異なる場合があります。
- `MorphForge > 本人プレビュー` は標準無効の実験機能です。512×384 の追加カメラ描画負荷が発生します。VR の快適さ、左右眼、ミラー等は実機で確認してください。
