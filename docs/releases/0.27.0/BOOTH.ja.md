# MorphForge｜ボクセル・図形・字幕を VRChat へ

Windows 用制作アプリ＋Avatar 導入プラグイン。
ボクセルを編集し、点や線を配置し、テキストやアニメーションを OSC で Avatar に送信できます。手動編集と内蔵サンプルは API Key 不要。自分の大規模言語モデル API を接続すると、AI 制作と字幕翻訳も利用できます。

【主な機能】
・ボクセル、三角面、点、太さを指定できる線分、デモ用図形。
・中・日・英のドット文字。半角／全角に対応し、文字サイズ・位置・行間を調整可能。
・音声字幕＋翻訳。原文を残し、中国語／日本語／英語へ翻訳。新しい字幕枠は4行（原文2＋翻訳2）が標準。
・グループアニメーション。移動・回転・一様拡縮、ループ／単発、停止／再開。
・Desktop はシステム言語に自動追従し、使用中にも切替可能。Unity は画面と Avatar メニューの言語を選択。
・544 種の標準材質、編集可能な内蔵作品サンプル。

【内容物】
MorphForge Desktop 0.27.0 Windows x64 インストーラー
MorphForge Avatar 1.4.0 Unitypackage
対応する公開材質カタログ ZIP
日本語・简体中文・English 導入ガイド、ライセンス、SHA256
人物アバター、SDK、Modular Avatar、NDMF、VRCFury、API Key、クラウド利用枠は付属しません。

【購入・導入前に】
Windows PC／PCVR 向け。Quest／Android 単体動作は未検証。
検証構成：Unity 2022.3.22f1、SDK 3.10.5、Modular Avatar 1.18.7、NDMF 1.14.8。VRCFury 1.1430.0 は任意。
標準モジュールは同期パラメーター253 bit を使用します。既存の衣装・顔トラッキング等と容量が競合します。VRCFury は OSC データを圧縮できません。容量超過時はビルドを停止します。
Very Poor ランクを前提とした機能実験用モジュールです。実機 FPS、すべての Avatar との互換性は保証しません。

【表示・同期の制限】
論理空間256³、設定容量16,384図形。本版では最大容量16Kのネットワーク無損失長時間試験を再実施していません。
テキスト最大4枠×128 UTF-16スロット（改行を含む）。字幕と通常テキストは枠数を共有します。
Avatar アニメーションは最大3グループ×4キーフレーム。編集画面の全アニメーション機能とは対応範囲が異なります。
送信完了はローカル UDP の完了です。受信実行 ACK はなく、途中参加や受信漏れは再送で補います。
新しい画像テクスチャ、Avatar メニュー言語の変更には再アップロードが必要です。汎用の物理コリジョンはありません。
本人プレビューは標準無効の実験機能で、追加カメラの描画負荷があります。
商品画像は Desktop の実画面・レンダリングです。VRChat 実機画像ではありません。

【AI・音声機能】
AI 制作・字幕翻訳はご自身の互換 API を使用し、サービス料金は別途発生します。小型 Silero VAD は付属。SenseVoice／Zipformer の認識モデルは別途ダウンロード、Tencent Cloud は自分の認証情報が必要です。録音・外部サービスは利用者が有効にします。
