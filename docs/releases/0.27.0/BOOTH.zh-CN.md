# MorphForge｜把体素、几何与字幕带进 VRChat

Windows 创作软件＋Avatar 安装插件。
编辑体素、放置点线，通过 OSC 将模型、文字与分组动画显示在自己的 Avatar 上。手动编辑和内置示例无需 API Key；连接自己的大模型 API 后，还可使用 AI 创作和字幕翻译。

【主要功能】
・体素、三角面、点、可调粗细线段，以及快速演示图形。
・中日英点阵字库，支持半宽／全宽排版、字号、位置、行距调整。
・实时字幕＋翻译，保留原文，可翻译为中文／日文／英文；新字幕框默认四行，原文与译文各两行。
・分组动画：平移、旋转、一致缩放、循环／单次、暂停／继续。
・Desktop 默认跟随系统，运行中可切换界面语言；Unity 可选择插件和 Avatar 菜单语言。
・544 项标准材质与可继续编辑的内置作品样例。

【下载内容】
MorphForge Desktop 0.27.0 Windows x64 安装器
MorphForge Avatar 1.4.0 Unitypackage
匹配的公共材质目录 ZIP
中文／日文／英文快速开始、许可与 SHA256
不包含人物 Avatar、SDK、Modular Avatar、NDMF、VRCFury、API Key 或云服务额度。

【使用前必读】
面向 Windows PC／PCVR，未验证 Quest／Android 独立运行。
已验证组合：Unity 2022.3.22f1、SDK 3.10.5、Modular Avatar 1.18.7、NDMF 1.14.8；可选 VRCFury 1.1430.0。
默认模块消耗253 bit同步参数，可能与服装、面捕等已有功能争用预算。VRCFury 无法压缩 OSC 数据，超预算会阻止构建。
这是以 Very Poor 性能等级为前提的功能实验模块，不承诺实机帧率或兼容所有 Avatar。

【显示与同步限制】
逻辑空间256³，配置容量16,384个几何对象；本版未重新完成满容量16K网络无损长测。
最多4个文本框，每框128个 UTF-16 槽（含换行）；普通文字和字幕共用框数。
Avatar动画最多3组×4关键帧，与编辑器完整动画的支持范围有区别。
发送完成仅代表本机 UDP 发完，没有远端执行 ACK；晚加入或漏接内容依赖补播。
新增图片纹理及修改 Avatar 菜单语言需要重新上传头像；无通用实体碰撞。
本人预览为默认关闭的实验功能，增加一份相机渲染开销。
商品图为 Desktop 实际界面与渲染，不是 VRChat 实机截图。

【AI 与语音】
AI 创作、字幕翻译使用自己的兼容 API，服务商费用另计。内置小型 Silero VAD，SenseVoice／Zipformer 识别模型另行下载，腾讯云识别需要自己的凭据。录音和外部服务由用户开启。
