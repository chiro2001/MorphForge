# MorphForge 0.27.0 快速开始

配套 MorphForge Avatar 插件 1.4.0。2026-10-25。

MorphForge 是 Windows 体素/几何创作工作台，可手动编辑、运行 Recipe，或连接自己的大模型辅助创作。安装配套模块并上传自己的 Avatar 后，可经 OSC 在 VRChat PC/PCVR 显示模型、点线、文字和分组动画。安装包不包含人物模型。

## 先检查环境

- Desktop：Windows x64、WebView2（Microsoft Edge）和可用的 WebGL 图形环境。本包不提供 macOS/Linux 安装器。
- Avatar：VCC Avatar 工程、Unity 2022.3.22f1、VRChat SDK 3.10.5、Modular Avatar 1.18.7、NDMF 1.14.8 为已验证组合。VRCFury 1.1430.0 可选；外部依赖不随包分发。
- 面向 PC/PCVR。未验证 Quest/Android 独立运行。当前模块以 Very Poor 性能等级为使用前提，不承诺实机帧率。
- 默认模块需要 **253 bit** 同步参数：240 bit 几何数据、13 bit 定位；请先备份 Avatar 并检查余量。VRCFury 仅可压缩适合的低频菜单参数，无法压缩 OSC 数据或连续面捕；最终超预算会阻止构建。

## 安装 Desktop

1. 运行 `Windows/MorphForge Desktop_0.27.0_x64-setup.exe`，按安装向导完成安装。
2. 打开 MorphForge Desktop，在“设置 > 界面与语言”选择跟随系统、简体中文、日本語或 English；切换即时生效。
3. 从作品库载入“会转动的风车”等内置示例。手动编辑、内置示例无需 API Key。
4. AI 创作和字幕翻译需要配置自己的兼容 Chat/Responses API；不附密钥或额度，调用费用由服务商另计。界面语言与提示词、识别、翻译目标语言相互独立。

## 安装 Avatar 模块

1. 备份场景，准备自己的 Humanoid Avatar。在 VCC 安装 SDK、Modular Avatar 及其 NDMF 依赖。
2. 导入 `Unity/MorphForgeAvatar-1.4.0.unitypackage`。
3. 打开 `Tools > MorphForge Avatar > Setup - 安装 - 設定`，选择目标 Avatar 和语言，点击安装。使用 VRCFury 压缩桥前先安装 VRCFury。
4. 已有 MF6 模块时先移除旧模块，避免重复接收。不要手动删除公共控制器中的 Write Defaults On。正常保存场景并通过 SDK 构建、上传。
5. 语言选择同时控制插件界面和该 Avatar 菜单；已装模块也可直接应用所选语言。**重新上传 Avatar 后，VRChat 菜单语言才会改变。**
6. 如 Desktop 未识别到对应的 544 项公共材质，导入 `Unity/MorphForge-public-catalog.zip`，然后重新识别 Avatar。此目录只适用于本包公共模块；私人纹理变体须导出自己的匹配目录。

## 首次发布与动画验证

1. 在 VRChat 换上已上传的 Avatar，开启 OSC。在 Desktop 连接页识别 Avatar，确认能力版本 **9** 和匹配材质目录。连接失败时检查本机 OSC 端口、防火墙及是否仍在使用旧头像缓存。
2. 在作品库载入“会转动的风车”，先在编辑器确认模型和循环旋转。
3. 唯一已保存动画会自动选中；有多个片段时，在主界面发布区域选择想播放的片段。点击“发布当前版本”会同时发布模型及所选动画。选择静态模式则只发送模型。
4. 等待所有发送阶段结束，在 VRChat 看风车叶片连续旋转。100% 表示本机 UDP 已发完，**没有远端执行 ACK**，不能据此保证所有玩家收到全部内容。
5. 晚加入或漏接内容时使用补播/循环补播；它发送最新模型、文本和动画定义。大模型传输需要时间，未承诺瞬间同步或跨端严格同相。

## 文字、点线、字幕

点线工具可直接指定线段两个端点、点的直径和线段粗细；使用专用指令与 Avatar 原生粒子/Shader 显示，共用几何容量，无需逐帧发送顶点。直径是空间尺寸，会随视距产生透视变化。

最多 4 个文本框，每框 128 个 UTF-16 槽（含换行）。中、日、英点阵字库支持半宽/全宽排版，字号、位置、朝向、行距、颜色和边界均可调；BMP 外字符可能显示缺字。文本排版在 Desktop 完成，Avatar 显示接收的文字与布局。

新建实时字幕默认固定字号、四行，原文和译文各保留最近最多两行。自动翻译可选中文、日文、英文，并保留原文；默认关闭，调用自己的大模型 API。手动修改过的旧字幕框保留自己的设置，必要时调整最大行数和溢出策略。文本框和实时字幕共用四框总量，可与体素及动画一起显示。

本包内置小型 Silero VAD；SenseVoice/Zipformer 识别权重需另行下载，腾讯云识别需自有凭据。录音、云服务与翻译均由用户开启，不附云服务额度。

## 范围、材质与性能

- 逻辑范围为 256³：X/Z -128…127，Y 0…255。Avatar 配置容量为 16,384 个几何对象；本版没有重新完成满容量 16K 网络无损长测。
- Avatar 动画最多 3 组×4 关键帧，支持平移、旋转、正均匀缩放及循环/单次、暂停/继续/定位。时长预设 0.125…64 秒；编辑器完整动画与 Avatar 支持范围有区别，以发布前检查结果为准。
- 新纯色、量化 PBR 和程序材质可实时发送；增加新的图片纹理需要在 Unity 生成匹配变体并重新上传 Avatar。
- 不提供通用实体碰撞。复杂场景、透明重叠与大量几何可能降低性能；请从小作品开始测试。编辑器预览不等于目标世界实际效果。
- “MorphForge > 本人预览”是默认关闭的实验功能，额外渲染 512×384 相机画面，会增加开销；VR 舒适度、左右眼及镜子效果需自行实测。
