MorphForge｜通过 OSC，把自己的模型带进 VRChat。

支持自定义体素和低多边形模型，内容不限于内置示例。用 Windows 工作台编辑、AI 建模和继续改稿，再通过 OSC 在自己的 Avatar 周围逐步搭建，制作小景观、随身道具、动画模型、像素画及点线文字演示。

免费版：0日元。

开源代码：https://github.com/chiro2001/MorphForge

【主要功能】
自定义体素／三角面建模，AI生成后继续编辑；OSC搭建与更新；世界固定、抓握缩放；分组动画；可调粗细点线；中日英文字；保留原文的实时字幕翻译；桌面和Unity安装界面中日英切换。

【下载内容】
Desktop 0.27.0 Windows x64安装器、Avatar 1.4.0 Unitypackage、匹配材质目录、三语导入指南、许可及SHA256。
人物Avatar、SDK、Modular Avatar、NDMF、API Key及云服务额度不包含在内。

【使用要求】
面向Windows PC／PCVR，需在Unity为自己的Avatar安装模块、上传并启用OSC。手工编辑与内置示例无需API Key；AI建模和翻译需配置自己的兼容API，服务费用另计。
已验证Unity 2022.3.22f1、SDK 3.10.5、MA 1.18.7、NDMF 1.14.8。标准模块使用253bit同步参数，会与衣服、面捕等功能共享预算。预期Very Poor等级，不承诺具体帧率或兼容所有Avatar。Quest／Android独立运行未验证。

【显示边界】
几何配置容量16,384；最多4个文本框×128 UTF-16槽；Avatar动画最多3组×4关键帧。新增图片纹理需重建头像，无通用物理碰撞。发送完成仅表示本机UDP发完，晚加入或漏收依赖补播。
