MorphForge｜自分のモデルを、OSCでVRChatへ。

ボクセルも、ローポリも、内蔵サンプルに限らず自分の作品を表示できます。
Windowsの制作アプリで編集・AIモデリングを行い、OSC経由で自分のAvatarの周囲に少しずつ構築。小さな風景、持ち歩ける小物、動く模型、ピクセルアート、説明用の点・線・テキストなどに使えます。

無料版：0円。
応援版：100円。内容・機能・ダウンロードファイルは無料版と同じです。応援は任意で、機能制限の解除ではありません。

【できること】
・ボクセル／三角面の制作、AI生成後の調整と手動編集
・OSCでモデルを構築・更新、ワールド固定、つかむ・拡大縮小
・移動・回転・一様拡縮によるグループアニメーション
・太さを指定できる点と線、中日英テキスト、リアルタイム字幕と翻訳
・原文を残す字幕翻訳。字幕枠は標準4行（原文2＋訳文2）
・DesktopとUnity導入画面の中国語・日本語・英語対応

【ダウンロード内容】
MorphForge Desktop 0.27.0（Windows x64インストーラー）
MorphForge Avatar 1.4.0（Unitypackage）と対応材質カタログ
日本語・中国語・英語の導入ガイド、ライセンス、SHA256
人物Avatar、VRChat SDK、Modular Avatar、NDMF、API Keyやクラウド利用枠は付属しません。

【導入前に】
Windows PC／PCVR向け。自分のAvatarへUnityでモジュールを導入し、アップロードしてOSCを有効にします。手動編集・内蔵サンプルはAPI Key不要。AI制作・字幕翻訳は自分の互換モデルAPIを設定し、利用料金は各サービスの条件に従います。

検証構成：Unity 2022.3.22f1、VRChat SDK 3.10.5、Modular Avatar 1.18.7、NDMF 1.14.8。VRCFuryは任意です。
標準モジュールは同期253bitを使用し、既存の衣装・面捕と容量を共有します。Very Poorランクを前提としており、実機FPSやすべてのAvatarとの互換性は保証しません。Quest／Android単体動作は未検証です。

【表示・同期について】
自作ボクセル／ローポリモデルも表示できますが、図形容量・材質・同期の制限があります。設定容量は16,384図形。新しい画像テクスチャの追加はAvatar再構築が必要で、汎用の物理コリジョンはありません。
テキストは最大4枠×128 UTF-16スロット。Avatarアニメーションは最大3グループ×4キーフレームです。
送信完了はローカルUDPの完了を示し、他の人への受信実行ACKではありません。途中参加や受信漏れには再送を使います。

【紹介動画・画像】
実際のAIモデリングGUIとVRChatでの構築を収録しています。AI生成24倍速、OSC構築32倍速などの加速と一部待ち時間の省略があり、瞬時の生成・転送を示すものではありません。
作品画像は保存済みのエディターレンダーで、実機映像とは区別して紹介しています。録画内のGUIやモデルの文字は元の内容を保持。人物Avatarや背景ワールドは商品の内容物ではありません。デモ作品は第三者の公認・提携を示しません。
