MorphForge｜あなたの作品を、VRChatへ。

持ち歩ける小さな風景、手に取って遊べる小物、動きのある説明模型。
Windowsの制作アプリで自作のボクセル・ローポリモデルをつくり、OSCでVRChatの空間に少しずつ構築。アイデアを、飾って、動かして、共有できる作品にできます。

【アイデアからモデルへ】
つくりたいものを言葉で伝えてAIで生成し、会話や手動編集で仕上げます。ボクセルや三角面を直接編集し、マテリアル・パーツ・保存済み作品を組み合わせる制作も楽しめます。

【VRChatで楽しむ】
・小さな風景、持ち歩ける小物、ピクセルアートを制作。
・自作モデルをOSCで送信し、少しずつ組み上がる様子を見ながら更新。
・つかむ、拡大縮小、ワールド固定で好きな場所へ配置。
・グループごとに移動・回転・一様拡縮アニメーションを設定し、メイン画面からモデルと選択中のアニメーションを一緒に送信。
・サイズを指定できる点、太さを指定できる線、中日英テキストで図解やデモを制作。
・音声をリアルタイム字幕として表示し、原文と訳文を同じ枠に表示。中国語・日本語・英語への翻訳に対応。
・ループ再送で、途中参加した人への作品共有をサポート。

【同梱内容】
MorphForge Desktop 0.27.0 Windows x64インストーラー
MorphForge Avatar 1.4.0 Unitypackageと対応マテリアルカタログ
日本語・中国語・英語の導入ガイド、各ライセンス、SHA256
Desktopはシステム言語への自動追従と使用中の言語切り替えに対応。Unity導入画面では表示言語とAvatarメニューの言語を選べます。

【はじめかた】
Windows PC／PCVR向け。Unityで自分のAvatarに表示モジュールを導入し、アップロード後にOSCを有効にすると、制作アプリから作品を送信できます。手動編集・サンプル作品・材質カタログから制作を始められます。自分の互換モデルAPIを接続すると、AIモデリングと字幕翻訳も利用できます。API料金は各サービスの条件に従います。
標準モジュールは同期253bitを使用し、想定性能ランクはVery Poorです。導入ガイドに依存関係・パラメーター容量・性能の説明をまとめています。
設定容量は16,384図形。テキストは4枠×128 UTF-16スロット、Avatarアニメーションは3グループ×4キーフレームに対応。

【実録で紹介】
実際のAIモデリングGUIとVRChatでの構築を収録。AI生成24倍速、OSC構築32倍速の過程と、等速の完成映像を組み合わせています。作品画像は保存済みのエディタープレビュー、遊び方の画像はVRChat実機映像からの抜粋です。
