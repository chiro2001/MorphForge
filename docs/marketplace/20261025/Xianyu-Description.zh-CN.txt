MorphForge 是一个免费、开源的 Windows 创作工具，配套 Avatar 安装插件。内容可以自己建、让AI生成后继续修改，不限于内置模型。视频里有大师剑的真实AI建模、VRChat逐步搭建、低多边形树和其他作品。

能做什么：
• 小景观、随身道具、像素画和点线文字演示
• 抓握、缩放、世界固定，以及分组动画
• 中日英文字、实时字幕、保留原文的字幕翻译
• 软件和Unity安装界面中日英切换

提供：Desktop 0.27.0 Windows安装器、Avatar 1.4.0 Unity插件、匹配材质目录、安装指南及许可。免费版功能完整。

需要 Windows PC／PCVR、自己的Avatar和Unity安装环境。标准模块占253bit同步参数，预期Very Poor等级，不保证具体帧率。人物Avatar和视频中的世界不包含在内，Quest独立运行未验证。

手工编辑、内置示例不用API Key；AI建模和翻译要配置自己的兼容API，服务商费用另计。视频有标注倍速及删减等待，不代表即时建模或即时传输。
