## 本轮结果

| 反馈 | 修改与验证 |
|---|---|
| 空载低帧 | 关闭空文本框Renderer，未用文字页、动画bank和材质输出按需计算；原生几何池空闲时停止复杂数据混合。成对Editor Animator均值约8.7→6.9ms，下降约20%。不是VRChat帧率结果；未宣称恢复70 FPS。 |
| 字符间隙不透明、发送后闪烁 | 字形码不再跨顶点插值，使用取整并限界的像素地址，空槽提前退出。中英文8格字间距、近远视角和轻微相机移动共90帧GPU测试，间隙异常像素0，同视角变化帧0。保留1bit字库。 |
| 点线粗细与逐面发送 | 新增独立点、方点和线段对象，点或线各一条OSC指令，含端点、RGB、直径（1/64格）；不增加同步参数或物理粒子。支持分组、变换、选择、擦除、保护、导出、动画、补播和删除。GPU点直径6→12格对应24→48px，线宽2→6格对应8→24px，端视仍可见；替换与补播没有增加粒子。 |
| Avatar动画不动 | 修复已有三角面绑定动画时未重新打标、桌面重启后播放票据碰撞，以及单次动画在定义排队时已经走完。首次播放等几何发送完成后起钟；常规补播保留相位。生产发送器250ms节奏数据进入Unity原生Animator和GPU，连续两周期、27种画面宽度、暂停/继续/停止通过。 |
| AI字幕与手动字幕不一致 | 共用caption预设：字号8、行距2、最多3行、保留末尾、底部对齐、透明背景，默认框128×32；位置、尺寸、朝向可配置。模型明确创建字幕或命名为字幕时使用该配置，禁止字幕缩字和无限行。普通文本仍可选缩字。 |
| 多行、混合显示与补播 | 排版在桌面完成，头像累加半宽/全宽和显式换行；短字幕用快照，长字幕分页。补播先恢复保存配置，再恢复最新实时内容。连续字幕更新不会饿死几何，已经开始的一组分页会完成，版本完成不再被瞬时字幕无限阻塞。修复补播计时提前问题。 |
| 新版本误报已提交 | 模型工具requestId由每次请求UUID和调用ID生成，避免服务商跨响应重复call_0命中旧回执；真实FakeResponses回归通过。 |
| 编辑器模型闪烁 | 相机near/far随作品与距离收紧，动画用完整运动包络，避免范围跳动；并发文字预览仅保留最新Mesh。原176方块作品未发现体积重叠/重复外表面，近远截图与静止画面稳定检查通过；仍需用户在原操作视角复验。 |

## 用户实机复验

1. 在VRChat切换到其他头像，再切回 **MorphForge MF6 16K**，确保重新加载v11。打开主程序，连接并重新识别头像；新能力声明为version8，支持原生点线和动画会话恢复。
2. 本人预览保持关闭，空载观察帧率；再发布当前revision51，分别记录静态、文字、动画的帧率。与此前相同场景和视角比较。
3. “演示”里加入点、粗细不同的线及组合示例；从正面、斜面、沿线方向观察，删除单个点线后补播，检查无残影、重复粒子或粗细失效。
4. 给文字设置较大字间距，混用中英文；发送结束后近远观察至少10秒，空白处应透明且稳定。普通文本框与字幕同时显示，输入超过三行时字幕保持字号、仅保留末尾三行；补播后仍为最新内容。
5. 选择动画并显式发布到Avatar，预期物体连续循环两个周期；暂停保持当前姿态、继续接着播放、停止恢复静态姿态。桌面重启后重新发布仍应运动，普通补播不应每轮从头跳回。0.125秒单次片段应在几何发完之后播放。
6. 在原编辑器预览中近远旋转模型，检查此前的闪烁；修改作品后提交，应在VRChat收到新版本，无需先重建。最后请另一位玩家观察点线、文字和动画。

这些头显、实际帧率和其他玩家视觉项目仍需要用户确认；服务端接受、Unity画面和本机发送完成均不代替远端视觉验收。
