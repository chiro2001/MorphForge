
オリジナル3DCGモデル　256Hedgehog
ver 1.2.0
-----------------------------------------------------------------------------------

このたびは、3Dモデルデータのダウンロード、誠にありがとうございます。
本データは、VRChat並びにVRM形式対応ソフトでの利用を想定して制作されたモデルですが、
利用規約の範囲内であれば、どのように利用して頂いても結構です。


●モデルデータについて●
====================================================================================
サンプルページ：https://hub.vroid.com/characters/8733884400386149513/models/1644751685041426417

Unitypackageに格納されているFBXファイルと、VRMでMaterial設定が異なります。
MToonを設定したMaterialを利用する場合には、「導入方法」を参考に、
UnityでVRMを扱う準備をしてからVRMのインポートを行ってください。
インポートファイルの中に、Materialも含まれています。


●導入方法●
====================================================================================
▼FBXを通常のゲームアセットとして利用する場合
    FBXを利用する場合には、添付のUnitypackageを任意のProjectへインポートしてください。
    VRChatのSDKに含まれるShaderを使用しているため、
　　Materialはエラーを起こしますが、正常な挙動です。
    Shaderをお手持ちのものに変更していただくと、エラーは解消されます。

▼VRMを利用する場合
    VRMを利用する場合には、UniVRM（Copyright © DWANGO Co., Ltd.）が必要となります。
    下記のURLからダウンロード後、モデルのインポート前に、
    任意のProjectへUniVRM（VRM 0.x）をUnityへインポートしてください。

    dwango on GitHub：https://dwango.github.io/vrm/

    UniVRMのインポート後、Asset内に利用したいVRMデータ単体をインポートして頂くと、
    Unityで編集が行える状態となります。

▼VRChatで利用する場合
    VRMを利用する場合には、VRCHAT SDK3が必要となります。
    WebからVRChatのマイページにログイン後、DownloadからVRCHAT SDK3 - AvatarsのUnityPackageを入手し、
    当データのインポート前に任意のProjectへUniVRMをUnityへインポートしてください。
    VRCHAT SDK2、またはVRCHAT SDK3 - Worldsでは
    添付Prefabが正常にインポートされませんのでご注意ください。

    VRChat:https://hello.vrchat.com/


●添付のPrefabについて●
====================================================================================
VRChatへのアップロード設定を行ったPrefabです。
Mobile版VRChat用Shaderである「Toon Standard」をMaterialに設定しており、
1つのPrefabでPC版・Mobile版どこにでもアップロードすることが可能です。


●添付のblendファイルについて●
====================================================================================
利用するにはBlender（https://www.blender.org/）、又はその他の対応ソフトのインストールが必要になります。
必要に応じて、重複した頂点のマージを行うことを推奨致します。
