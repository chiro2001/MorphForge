## B：持久文本对象与二值字库（0.18.0开发）

- 官方GNU Unifont 18.0.01 HEX与JP BDF转换为BMP定址R8打包字库。每套2,097,152字节位图+65,536字节宽度表，57,086字形；两套4.125MiB像素/宽度载荷，不是Avatar下载增量。转换脚本、内容哈希、版权与OFL许可随源码保留。
- 文本框进入Scene事务，参与保存/重开、撤销/重做、清空/分组删除、保护分组、整体平移、范围及容量检查。AI新增text_panels工具，体素文字仍为默认。
- Rust排版实现半全宽、NFC、自动换行、英文短词整体换行、常见标点避头尾、对齐、裁切/保留末尾/缩小。BMP外字符显示缺字并在回执列出。
- 编辑器增加文本框模式、输入与即时预览、精确变换和方向按钮、平面拖动；字形Shader使用同一字库，正反面同时翻转布局坐标，背面整行与每字均正常可读。
- 浏览器8项通过，包含真实字体Shader、输入应用、撤销、方向按钮、正反面截图像素对比与无JS/GPU错误。见stage-b-browser。

### C/D实测记录（2026-10-22）

0.19.0冻结输入构建完成。Rust语音HTTP5项通过，包含后台离线回调正确进入现有Tokio运行时。Windows CPAL最初遇到Cable设备的非f32格式，已支持标准整数/浮点格式并实际采集验证。识别取消/停止幂等；AI持有编辑权时字幕保留在语音草稿，明确提示暂停后应用，不直接修改建模中的Scene。

实际Cable测试38项通过，完整证据stage-c-speech/validation.json。3条共同中文SAPI语料中，两种离线方案标点归一化CER均0；离线句末接收端估计约499～506ms，混合约497～503ms，其中VAD等待450ms，SenseVoice推理约46～56ms。播放端估计末音到可见final约1.0～1.07秒，包含Cable输出缓冲及轮询，不能作为纯推理时延。冷加载离线约1.81秒、混合约2.53秒。小样本未显示混合能加快最终提交，默认保留offline；hybrid提供临时文字，首次partial相对回放开始约1.52～1.55秒（含前导/缓冲）。报告中的preferredBySmallCohort仅是旧脚本的中间结果启发式，不用于选择默认值，不把3条中文语料扩展为多语言/噪声覆盖结论。

真实关键词触发仅提交一次本地fixture模型，“不要开始建模”不触发；最终字幕更新指定文本对象，轮询不重复修改。静音2秒零云连接。腾讯真实短句识别一次成功，上传音频2.892秒、1会话，未查询账单，不推断实际扣费。测试没有使用真实大模型或发送VRChat OSC，不改默认声卡。
