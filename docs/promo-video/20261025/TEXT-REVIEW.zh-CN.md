# 宣传片文字精简审查

用户要求逐处判断文字是否必要，让画面承担展示。按17个镜头审查了新增标题、解释、标识、来源与字幕，并检查截图中是否带入无关信息。每项删留记录在 `text-review.json`。

删除所有常驻M／MorphForge标识、章节编号、进度线、逐镜解释段落、「实机」「原速」「已防抖」标签、功能清单、安装步骤和调试／版本／上下文信息。品牌只在片头与片尾出现。一般功能仅保留一条2–6字短标题，约2.2秒后完全消失；日英字幕也改为对应短语，出现约2.4秒，不再整段叠加解释。
