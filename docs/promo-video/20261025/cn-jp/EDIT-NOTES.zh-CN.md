# 作品拼贴、中日独立版及低多边形树

本轮按反馈将 MLP 从上版总计16秒（开场3.2秒＋后段12.8秒）缩到3.2秒，只作为点线文字的一个例子。开场对应镜头换成实机风车。新增三组双图作品拼贴9.6秒，使用个人作品库已保存的跑车、拉面、夜鹭、枫树、小屋和静物；图片为真实软件渲染，标注“作品预览／作品プレビュー”，不当作VRChat实机。来源和图片摘要见 `artwork-sources.json`。

用户补充的低多边形树来自 `可能需要加一下防抖。.mp4`。选用原片6.4–12.8秒，原速，按用户的画面撕裂反馈取消后期防抖，保留原始相机运动。与体素作品和实机搭建并列，展示不同几何风格。原片未改。

本版111.2秒，1920×1080，60fps，19镜头。中日两部成片各自从原始素材渲染图形层：片头功能说明、AI建模标题、OSC搭建标题、作品图标识、树／MLP／其他功能标题、片尾CTA、封面和分镜都按语言制作。中文SC、日文JP。日文片不叠中文设计标题，也不依靠切换字幕来获得日文画面。无新增配音，继续BGM。

录制中的原始GUI和模型本体文字保留真实内容（GUI为中文，MLP模型内有中文说明，字幕实机牌本身为中日双语）。这些不冒充已切换界面的日语录制；没有覆盖或伪造软件操作。音乐曲名、作者和CC许可地址保留标准署名。
