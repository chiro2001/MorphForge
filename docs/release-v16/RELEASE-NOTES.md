MorphForge 0.16.0：自动发布规划、Avatar 材质识别与多实例工作台。

Windows x64 正式安装包，按当前用户安装。升级前建议退出旧窗口；原工程、作品库和对话继续保留。

- 自动比较增量、Clear 重建、连续区域编码与安全同材质合并的实际发包成本；加入本机发送进度条。
- 读取 Avatar 的不同步能力参数，按完整目录哈希识别协议及贴图库；不作为执行 ACK。
- 多实例独立工程与上下文、共享作品库，OSC 单实例独占；窗口浏览器缓存独立并复用空闲槽。
- 输入区新增自动／体素／多面体／混合类型，以及自动／指定 XYZ 尺寸；支持删除用户作品。
- 修复艺术／VRC 光照切换的视角跳变、树叶透空显示、定位球抓握以及共面闪烁。
- Minecraft 建筑按形状与目标空间自动选择格精度；材质构建支持去重、多组纹理数组和开销估算。私人配套 Avatar v5 已含原版 1.21.1 材质；公开安装包仅包含原创资源，用户可导入自己的资源包。
- 运行发送统一为 MF6，停用 MF2–MF5 发送入口；历史工程继续可读。

验证：Rust 工作区251项、Node58项、Windows原生界面22项、多实例16项、桌面单元3项及Unity验证通过；配套Avatar三项服务端分析通过。

发送完成仅表示本机UDP写出，不能确认其他玩家完整接收；保留延迟档位与周期／连续补播。Avatar更新后需要重新切换加载，按需识别目录。新的工具说明使用schema4.2，旧对话可新开或显式升级，升级需要重新预热前缀缓存。

资产：安装包、SHA-256校验清单和构建输入清单。源码与详细验证见仓库 `docs/stream-v16/RESULTS.md`、`docs/release-v16/RESULTS.md`。
