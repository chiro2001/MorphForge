# 0.5.0：大上下文、完整输出与离线作品库

日期：2026-10-19。提示词 `morphforge-system/4.5`，工具定义 `morphforge-tools/3.2`。

## 默认预算与上游限制

三档预设共用1,048,576 Token上下文、393,216 Token单步输出上限，自动compact阈值900,000。草稿/标准/精雕分别允许12/24/128步、200万/800万/3200万累计Token、1/2/6小时。扩大容量不代表每次请求必须生成至上限。

连接首次运行和模型列表刷新读取 `/models`，识别常见上下文字段与输出上限；连接切换清理缓存。未提供元数据时按用户配置，不猜测能力。配置页显示实际有效上限，同时保留用户配置值。实际请求输出取配置上限、上游输出上限、剩余累计预算、共享上下文剩余空间减1024余量的最小值。900k输入仍能使用剩余窗口，不会因完整384K输出预留而提前拒绝。

[官方模型元数据](upstream-models.json)由带鉴权的真实GET获取，记录已去掉认证信息；返回1,048,576上下文与393,216输出。该次核查没有发送生成请求。模型HTTP请求改用运行deadline和取消信号控制，移除旧240秒总超时；模型列表和图片上传各有独立较短超时。SSE总保护256MiB、单帧16MiB，诊断尾部最多128帧。

旧配置新增预算版本标记，仅首次迁移匹配旧默认值的字段，自定义设置保留。迁移后用户主动设回旧数值也不会在下次启动被覆盖。compact后重置旧输入估算基线；近满窗口且仅有两组完整工具批次时只保留最近一组，避免全部历史再次被送入摘要。
