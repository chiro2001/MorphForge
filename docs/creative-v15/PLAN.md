# 0.15 创作扩展

用户于2026-10-20选择参考图对照、可复用组件库（同对话供Harness使用）和动画，授权实现。

1. 项目保存命名相机/参考图对照、组件与分组动画。读取旧项目使用空默认值；项目切换隔离，元数据有独立版本检查。几何编辑继续使用现有revision、保护分组、撤销和运行取消守卫。
2. 对照窗口提供图库选择、并排/叠加、透明度/偏移/缩放/裁剪、当前相机书签和截图。相机/对照设置可由Harness查询与复用，不自动改变旧上下文静态前缀。
3. 组件由选区或分组保存，地面中心为默认原点；按整数倍缩放、四向旋转、镜像、位置/分组/样式覆盖批量放置。组件保留原几何，实例展开为普通可编辑对象；支持dryRun、幂等与撤销。首版不承诺减小OSC数据量。
4. 动画以分组为目标，枢轴+平移/XYZ旋转/正缩放关键帧，线性或阶梯插值、循环、拖动与播放。仅显示预览，不改草稿或触发OSC；支持Harness设定、指定时刻截图和GLB动画导出。
5. Avatar的MF6仍发布静态几何，没有播放轨道的接收器。独立评估运动定义传输/Shader存储的条件；本轮不把桌面动画宣称为VRC端到端播放，不自动上传头像。
6. 中文优先工具说明，提升工具版本，沿用旧对话显式升级/新开对话机制，普通请求保持append-only。离线API/浏览器/Windows原生验证后安装Preview、提交同步，不创建Release。
