# 实时字幕自动翻译（Desktop 0.24.0）

实时字幕新增自动翻译，目标语言为**中文（简体）、日文、英文**。翻译在桌面端调用已有大模型API连接，译文通过原有文字协议显示，沿用Avatar 1.3.0。默认关闭。

## 使用

1. 在“设置→大模型连接”配置可用API。
2. 在语音小窗选择字幕框，开启“自动翻译”，选择目标语言。
3. 语音开启“自动同步到选定文本框”后，识别字幕自动翻译；也可修正原文后点击“应用文字”。主界面文本框的“实时更新”使用同一翻译链路。
4. “设置→语音识别与输入”中可指定翻译模型；留空使用当前建模模型，点击“保存语音设置”保存。

小窗保留可编辑原文，单独显示译文及翻译状态。原有固定字号、最大行数、位置与补播继续适用。关闭翻译后恢复原文输出；API失败时回退原文并显示错误。等待译文期间手工修改字幕时，保留手工修改，旧结果不写回。

## 实现与边界

- 支持现有Responses和Chat Completions两种连接。使用独立的无工具请求，不把建模对话发送给翻译模型，也不修改建模的上下文前缀、缓存保护或轮次预算。
- 流式临时文字等待约600ms稳定后合并请求；句末结果直接进入队列。每个字幕目标仅保留最新待处理版本，一个worker执行请求；16项结果缓存减少重复翻译。同一内容的临时稿和终稿可复用结果。
- 只发送最近1200个Unicode字符作为字幕窗口；请求超时15秒，输出上限1024 token。长时间录音不反复发送整个累积草稿。返回内容仍经过字幕框的固定字号、最大行数和保留末尾排版。
- 切换语言、关闭翻译、清空草稿、取消/新建录音会话会使旧请求失效；项目切换、目标删除、手工改字也不能被延迟结果覆盖。排队中的请求遇到模型连接变化时要求重新应用字幕。
- 翻译请求会使用所配置API的用量，最后一次usage与调用次数可在`/api/speech`状态中查看；不计入建模会话预算。真实翻译质量和延迟取决于用户所选模型，本轮未调用付费API评测质量。
- 没有自动启用翻译、真实麦克风、腾讯云识别或VRChat发送。
