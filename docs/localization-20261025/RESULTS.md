# 中日英多语言（2026-10-25）

Desktop **0.27.0**、Unity Avatar 安装插件 **1.4.0** 支持简体中文、日文、英文。

## 桌面端

“设置 > 界面与语言”提供跟随系统、简体中文、日本語、English。默认跟随系统；Windows 使用用户的系统界面语言，其他系统结合环境与浏览器首选语言，未匹配时回退到英文。手动选择在本机 `ui-settings.json` 保存，重启和端口变化后仍保留。

切换无需重新载入页面，主窗口和 Mini 窗口同步。包含主菜单、配置、帮助、弹窗、点线演示、文本框、动画和动态状态，共 1,254 条界面词条。只对标记的界面文字和程序诊断进行翻译，不扫描或替换作品名称、用户输入、识别原文、译文、模型输出及源码。界面语言独立于提示词工具语言、语音识别语言和字幕翻译语言。

启动页与原生启动错误也使用相同的语言选择。语言切换不提交作品、不调用模型、不启动录音或 OSC。

## Unity 插件

打开 `Tools > MorphForge Avatar > Setup - 安装 - 設定`，在窗口顶部选择语言。首次根据系统语言选择，之后记住手动选择。插件界面和新安装的 Avatar 菜单使用该语言；已选场景 Avatar 已安装模块时，切换语言也会更新其菜单。之后选择的 Avatar 可点击“将当前语言应用到所选 Avatar 菜单”，无需卸载模块。

每个安装实例生成独立、可持久保存的菜单资源，位置在 `Variants/LocalizedMenus/<实例>/<语言>`。菜单关联、目标子菜单、图标、参数、材质、几何与控制器保持原语义。公共模板及其他 Avatar 不受切换影响，自定义控件保留。场景重新打开后语言保留；**需要重新上传 Avatar 才能更新 VRChat 中的菜单**。
